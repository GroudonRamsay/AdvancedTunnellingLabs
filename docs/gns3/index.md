## GNS3

GNS3 is a network emulation platform used to build and test virtual networking environments.

It supports several routers from different vendors, switches, Linux devices, docker containers and in-built packet capture.

The GNS3 used to develop the labs was installed in Windows, and used the GNS3 VM in VMWare.

## Installation

To download and install GNS3, its necessary extensions and additional programs, we recommend following this guide: [https://docs.gns3.com/docs/getting-started/installation/windows](https://docs.gns3.com/docs/getting-started/installation/windows)

## Appliances

We used a myriad of different devices for our GNS3 laboratories. Most of these devices do not come with GNS3. You can find some in: [https://gns3.com/marketplace/appliances](https://gns3.com/marketplace/appliances)

The docker containers used can be easily obtained using the given container name and following any guide on how to install them.
