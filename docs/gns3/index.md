## GNS3

GNS3 is a network emulation platform used to build and test virtual networking environments.

It supports routers from several vendors, switches, Linux devices, Docker containers, and built-in packet capture.

The version of GNS3 used to develop these laboratories was installed on Windows and used the GNS3 VM running in VMware.

## Installation

To download and install GNS3, its required extensions, and any additional programs, we recommend following this guide: [https://docs.gns3.com/docs/getting-started/installation/windows](https://docs.gns3.com/docs/getting-started/installation/windows)

## Appliances

We used a wide variety of devices for our GNS3 laboratories. Most of these devices are not included with GNS3. Some are available at: [https://gns3.com/marketplace/appliances](https://gns3.com/marketplace/appliances)

The Docker containers used in the laboratories can be easily obtained by using the provided container name and following a guide on how to install them.
