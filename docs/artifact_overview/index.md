## Artifact Overview

Secure Tunneling Labs is an open-source laboratory package for reproducible experimentation with secure tunneling and secure-channel protocols.

## Components

- Documentation website
- Protocol-specific topologies
- Router, switch, and host configurations
- OpenSSL command sequences
- Wireshark capture workflows
- Attack and failure experiments
- Expected outputs and packet-analysis tasks

## Supported Protocols

- MACsec
- ANYsec
- IPsec
- WireGuard
- TLS
- DTLS
- SSH
- PKI
- Post-quantum and hybrid key-establishment experiments

## Intended Use

- Teaching
- Self-study
- Packet-level protocol analysis
- Reproducible secure-tunnel experimentation
- Companion artifact for the Computer Networks Open-Source Software Article

## What the Artifact Is Not

This artifact is not a new secure-tunneling protocol and is not primarily a software implementation of MACsec, IPsec, WireGuard, TLS, DTLS, or SSH. Its contribution is the integration of reproducible topologies, configurations, packet captures, guided experiments, and failure cases for studying secure tunneling protocols.
