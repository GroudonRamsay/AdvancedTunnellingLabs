# Advanced Tunnelling Laboratories

Welcome to the Advanced Tunnelling Laboratories repository website.
In this repository, we aim to bring several laboratories focused on showcasing
Tunnelling protocols, and their many features, strengths and weaknesses.

## Emulator Setup

- [ContainerLab](containerlab/index.md) - Setup guide for ContainerLab
- [GNS3](gns3/index.md) - Setup guide for GNS3

## Protocol Documentation

- [MACsec](macsec/index.md) - Layer 2 hop-by-hop encryption using IEEE 802.1AE
- [WireGuard](wireguard/index.md) - Modern lightweight VPN tunnelling
- [IPsec](ipsec/index.md) - Enterprise-grade encrypted IP transport
- [TLS](tls/index.md) - Secure TCP application transport
- [DTLS](dtls/index.md) - TLS security for UDP-based transport
- [SSH](ssh/index.md) - Secure shell administration and tunnelling

## Features

- ContainerLab setup and guides
- GNS3 setup and guides
- Full configuration guides for all protocols
