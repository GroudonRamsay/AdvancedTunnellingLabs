# Advanced Tunnelling Laboratories

Welcome to the Advanced Tunnelling Laboratories repository.
In this website, we aim to bring several laboratories focused on showcasing
Tunnelling protocols.

This website contains two setup guides for the emulators used, GNS3 and ContainerLab, to help prepare the test environment.

There are also several guides, each focusing on a different Tunnelling protocol, providing a brief overview of the protocol and its features, explaining the emulator used, devices and topology chosen for the demonstration, the configurations needed for everything to run properly and then several questions to help the learning process.

We hope you enjoy these laboratories, and that they help you learn about Internet and its safety!

## Emulator Setup

- [ContainerLab](containerlab/index.md) - Setup guide for ContainerLab
- [GNS3](gns3/index.md) - Setup guide for GNS3

## Protocol Guides

- [MACsec](macsec/index.md) - Layer 2 hop-by-hop encryption
- [WireGuard](wireguard/index.md) - Modern lightweight VPN tunnelling
- [IPsec](ipsec/index.md) - Enterprise-grade encrypted IP transport
- [TLS](tls/index.md) - Secure TCP-based application transport
- [DTLS](dtls/index.md) - TLS security for UDP-based transport
- [SSH](ssh/index.md) - Secure shell administration and tunnelling
